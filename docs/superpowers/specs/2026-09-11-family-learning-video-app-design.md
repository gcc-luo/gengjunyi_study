# 家庭儿童视频学习 App 设计规格

**日期：** 2026-09-11

**依据：** `docs/家庭儿童视频学习App_MVP_PRD_v1.0.docx`

## 目标

交付一个可直接运行的前端 MVP，覆盖家长 Web 管理端与儿童 App 端的核心学习闭环：家长创建课程、维护视频和孩子档案；儿童选择孩子、浏览课程、播放视频、保存进度并查看学习记录。

本轮不接入真实后端、账号体系或真实文件服务器。数据通过浏览器 `localStorage` 持久化，上传使用可取消、可重试、逐文件反馈的前端模拟队列；播放器保留真实的播放控制与学习进度逻辑，因此后续可以把数据层替换为 API 而不改变页面交互。

## 范围

### 家长端 P0

- 概览：课程数、视频数、孩子数、今日学习时长；最近上传课程；近 7 天孩子学习对比；最近学习动态。
- 课程管理：课程搜索、学科/年级/状态筛选、新建与编辑、查看详情、视频列表排序、发布和下架。
- 视频上传：多文件选择或拖拽、MP4/MOV 格式校验、自然排序、逐文件进度、取消、失败重试、上传完成后创建视频记录。
- 孩子管理：新增、编辑、停用孩子；展示可见课程数和最近学习时间；进入该孩子的学习记录。
- 学习记录：按孩子、时间范围和学科筛选；今日学习、本周完成、连续学习天数；近 7 天趋势；明细表。
- 设置：展示本地数据/存储使用情况，并提供儿童端偏好开关。

### 儿童端 P0

- 选择孩子：展示所有启用的孩子和家长入口。
- 首页：继续学习、学科分类、我的课程、底部三栏导航。
- 课程列表与详情：课程封面、学科、适龄信息、课程进度、课程目录/介绍 Tab、自由选择任意视频。
- 视频播放：播放/暂停、进度条、当前时间/总时长、全屏、快退/快进 10 秒、上一集/下一集、基础倍速、收藏课程、退出保存进度。
- 学习记录：统计/历史切换、今日学习、本周完成、连续学习、近 7 天图表和动态列表。
- 我的：当前孩子资料、已学课程、完成视频、学习天数、我的课程、学习记录、收藏、切换孩子、护眼模式、关于我们。

### 明确不做

真实登录鉴权、后端数据库、真实上传到服务器、复杂转码、多码率、社交、评论、推荐流、付费、题库、AI 能力和课程锁定。

## 视觉与交互基准

PRD 内嵌原型截图是最高优先级的视觉参考，设计不另起一套风格。

### 儿童端

- 使用原型中的窄屏手机比例，页面背景为浅蓝天空渐变，底部或页面背景保留柔和山丘/云朵氛围。
- 主色为原型蓝 `#2D86F5`，标题与主要文字为深藏蓝 `#0B235A`；完成态使用浅绿色；学科入口使用红、蓝、黄、紫四种区分色。
- 使用圆角白色卡片、轻阴影、细边框和大触控区域。儿童端不使用密集表格，不出现广告、评论或推荐流。
- 选择孩子页保持“谁来学习？”标题、头像卡片、底部绿色场景与“家长入口”按钮的层级。
- 首页保持问候区、继续学习主卡、四个学科入口和课程列表的顺序。
- 课程详情保持课程信息头、进度条、Tab 和纵向分集列表。原型中的锁图标不实现锁课，所有可播放视频均可直接进入。
- 播放页保持黑色视频区域、蓝色中央播放按钮、快退/快进、上下集、收藏和课程简介模块。
- 学习记录与我的页面保持三项统计卡、趋势图/动态列表、分组入口和开关的层级。

### 家长端

- 使用原型中的桌面工作台：左侧固定导航，顶部搜索框、蓝色“新增课程”按钮和家长账号区。
- 内容区采用白底、浅灰蓝边框、紧凑卡片、蓝色选中态和蓝色文字操作。概览使用四指标卡加双栏内容；课程管理和学习记录使用紧凑表格；视频上传使用左侧大拖拽区加右侧上传设置；孩子管理使用双卡片布局。
- 新建/编辑课程、孩子档案和详情编辑采用右侧抽屉或居中弹层；危险操作用二次确认；成功、失败和重试使用局部提示，不阻断其他卡片。
- 字体采用有性格的衬线标题字体搭配清晰的无衬线正文，整体对齐、间距和控件比例贴近 PRD 原型，不使用紫色渐变或模板化仪表盘样式。

## 应用结构

采用 React + TypeScript + Vite 单应用，以 URL 路由区分端和页面：

- `/parent/overview`
- `/parent/courses`
- `/parent/uploads`
- `/parent/children`
- `/parent/records`
- `/parent/settings`
- `/child/select`
- `/child/home`
- `/child/courses`
- `/child/course/:courseId`
- `/child/watch/:videoId`
- `/child/records`
- `/child/me`

页面层只负责展示和交互；领域数据通过 `AppStore` 读写，`storage` 模块负责序列化和初始化演示数据。这样可以保持父端和儿童端统计口径一致，也便于未来接入真实 API。

## 数据与业务规则

核心实体为 `Child`、`Subject`、`Course`、`Video`、`WatchProgress`、`WatchEvent` 和 `Favorite`。课程状态为 `DRAFT`、`PUBLISHED`、`OFFLINE`；视频状态为 `UPLOADING`、`READY`、`FAILED`。

- 发布课程必须有课程名称、学科和至少一个可播放视频。
- 下架后儿童端隐藏课程，但不删除学习历史。
- 视频默认按文件名自然排序，课程详情支持上移/下移。
- 当前孩子是所有儿童端统计和进度查询的作用域；切换孩子后所有数据立即切换。
- `lastPosition` 用于断点续播，可前后变化；`maxProgress` 只增不减。
- `maxProgress >= 90%` 时 `completed = true`。
- 只有播放状态才累计 `effectiveWatchSeconds`；暂停和后台停留不累计。
- 演示播放器每 10 秒保存一次播放心跳，离开播放器时再保存一次。
- 首页“继续学习”取当前孩子最近观看且未完成的视频一条。
- 课程进度为已完成视频数除以当前课程可播放视频总数。
- 连续学习天数按每日有效学习达到 1 分钟计算。

## 异常和空状态

- 无课程：展示“还没有课程，创建第一门课程”或儿童端“请让家长添加学习内容”。
- 无孩子：家长端引导创建孩子，儿童端停留在选择孩子/不可进入首页状态。
- 无学习记录：趋势图和明细使用明确空状态，不填充虚假数据。
- 上传格式不支持：加入队列前阻止并提示支持 MP4/MOV；单文件失败不影响其他文件。
- 上传取消：仅允许取消等待中或上传中的任务，已完成任务只能从课程详情删除。
- 发布失败：保持原状态，显示可重试提示。
- 视频不可播放：详情项标记“暂不可播放”，其他视频仍可进入。
- 下架课程：从儿童端列表隐藏，已存在的历史记录保留。
- 所有列表、统计卡和图表支持局部加载失败或重试反馈。

## 验证设计

验证分三层：

1. 领域逻辑测试：自然排序、发布校验、课程进度、90% 完成判定、最大进度只增不减、按孩子隔离数据、有效播放时长累计。
2. 页面交互测试：家长创建并发布课程；上传队列逐文件反馈；新增两个孩子；儿童选孩子、选课、播放、退出和继续学习；切换孩子后统计隔离；下架后课程消失但记录保留。
3. 浏览器验收：使用 Playwright 启动 Vite，验证核心页面渲染、关键按钮可操作、路由跳转无控制台错误，并检查桌面家长端与窄屏儿童端截图的布局。

## 验收标准

- 家长可以创建课程、添加至少一个演示视频并发布。
- 发布课程刷新儿童端后可见，且按学科进入课程详情。
- 儿童选择孩子后进入首页，继续学习卡片能进入最近未完成视频。
- 播放器退出后再次进入，断点位置能恢复；暂停时长不增长；达到 90% 后视频完成。
- 家长端和儿童端对同一孩子的今日学习时长一致。
- 切换到第二个孩子后，同一视频使用独立进度。
- 课程下架后儿童端不再展示，历史学习记录仍可查询。
- 页面风格、导航位置、卡片层级和核心交互与 PRD 原型截图保持高度一致。
