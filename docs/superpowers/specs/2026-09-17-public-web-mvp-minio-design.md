# 公网家庭儿童视频学习 Web MVP 设计规格

**日期：** 2026-09-17

**依据：** `docs/家庭儿童视频学习App_MVP_PRD_v1.0.docx`、现有前端实现与用户确认的范围

## 目标

把目前基于浏览器本地存储、模拟上传和演示播放器的前端，升级为可在公网实际使用的单家庭 Web 产品。家长可从任意网络登录并管理课程、孩子和学习记录；孩子可在手机浏览器中观看实际视频，进度跨设备保存。

V1 部署到 Ubuntu 云服务器，首年视频库按不超过 100 GB 设计。V1 不做原生 Android App，不开放注册，不支持多个家庭，不做视频转码，也不纳入备份与恢复。

## 已确认的产品边界

- 一个部署实例对应一个家庭；由一位家长管理员登录并管理多个孩子档案。
- 服务公开可达，但内容和媒体必须经过身份与权限检查；不提供公开注册或匿名媒体访问。
- 视频存储使用同一 Ubuntu 云服务器上运行的 MinIO 私有桶。MinIO 控制台不暴露给公网。
- 应用对媒体库设置 100 GB 逻辑容量上限，并提示容量告警；云硬盘需为系统、数据库、临时数据留出额外空间。
- 首版上传格式为 MP4，目标编码 H.264/AAC；不提供转码和多码率处理。
- 不纳入备份。服务器或存储盘损坏、误删或账号失陷可能导致数据无法恢复；不承诺高可用。

## 架构

继续使用现有 React、TypeScript、Vite 前端；增加 TypeScript/Fastify API、PostgreSQL 与 MinIO。Ubuntu 使用 Docker Compose 管理服务。Caddy 作为公网 HTTPS 入口，应用前端与 API 使用同一站点；MinIO S3 API 使用独立的 HTTPS 主机名并通过精确 CORS 规则允许应用站点访问。MinIO 管理控制台只允许通过 SSH 隧道或服务器本机访问。

服务边界如下：

- **Web 前端：** 保留 PRD 的家长端和儿童端信息架构，负责交互、上传队列和原生 HTML 视频播放。
- **API：** 负责登录会话、权限、业务校验、课程/孩子/学习记录 CRUD、上传会话签发、媒体状态流转和播放授权。
- **PostgreSQL：** 保存家长凭据摘要、孩子、学科、课程、视频元数据、上传会话、观看进度、有效学习事件与收藏。
- **MediaService：** 隔离对象存储实现；V1 使用 MinIO 的 S3 兼容接口保存、读取、列举和删除对象。业务表只保存稳定的对象 key，不保存长期公开 URL。
- **Ubuntu 运维层：** 持久化挂载 MinIO 与 PostgreSQL 数据目录；仅公开 80/443，SSH 使用密钥访问；记录服务错误并监测磁盘与 MinIO 健康状态。

## 身份、权限与隐私

- 首次部署通过服务器 CLI 创建家长管理员，不提供公开注册；忘记密码通过服务器 CLI 重置。
- 密码使用 Argon2id 保存摘要；登录使用 Secure、HttpOnly、SameSite Cookie 会话，并实施登录限速、CSRF 防护和严格的来源校验。
- 家长端路由与 API 必须要求家长会话。儿童端须在有效会话内选择启用的孩子档案；所有儿童数据查询与写入均由服务端校验该档案属于此部署实例且仍启用。
- 课程发布只允许 READY 视频；下架课程不可从儿童端新进入，但既有学习记录保留。
- 私有 MinIO 桶关闭匿名读写和列举。浏览器只使用 API 为已授权对象签发的预签名地址；上传分片地址有效期为 15 分钟，播放地址有效期为 2 小时，地址按需续签且续签后从原播放位置恢复。日志不得记录密码、会话 Cookie 或完整预签名 URL。
- 不采集真实儿童姓名、生日等非必要个人信息；孩子昵称和年级仅供本家庭学习体验使用。

## 主要数据流

### 上传

1. 家长登录，选择课程及一个或多个 MP4 文件。
2. 前端向 API 请求创建上传会话；API 校验课程权限、文件名、声明大小、扩展名和媒体库配额，预留对应空间。
3. API 创建 MinIO multipart upload，并向浏览器签发 15 分钟有效、限定对象与分片编号的上传 URL。浏览器直接向 MinIO 分片上传，避免视频字节经过 API 进程；前端显示逐文件进度并支持失败重试和续传。续传时 API 查询已完成分片并重新签发尚需上传分片的 URL。
4. 浏览器通知 API 完成上传；API 完成 multipart、核实对象大小，并用 ffprobe 验证容器、视频/音频编码和时长。状态按 `UPLOADING → PROCESSING → READY/FAILED` 转移。
5. 校验失败的对象不能发布；保留明确失败原因并支持重试或删除。用户删除视频时，API 删除对应对象和元数据；连续 7 天未活动的 multipart 会被清理并释放配额。

上传校验与配额以服务端结果为准，不能信任浏览器 MIME 类型或客户端提供的文件大小。100 GB 配额按已完成对象实际字节数加活动上传预留字节数计算；不同文件之间互相独立，一个失败不阻止其余队列完成。

### 播放与学习记录

1. 儿童在已登录会话中选择档案、打开已发布课程并请求播放视频。
2. API 校验档案、课程和视频状态后签发 2 小时有效的 MinIO GET 地址；媒体桶仍保持私有。播放器使用 MP4 HTTP Range 请求支持跳播和拖动。
3. 播放器每 10 秒以及暂停、切集、退出时上报播放位置和有效观看秒数；API 校验视频/孩子关系并以孩子与视频为键更新进度，事件用于家长端统计。
4. 续播使用最近位置；最大观看进度只增不减，达到 90% 判定完成。2 小时播放地址过期时，前端重新请求授权并从当前播放位置继续。

## 领域规则

- 课程状态为 `DRAFT`、`PUBLISHED`、`OFFLINE`；媒体状态为 `UPLOADING`、`PROCESSING`、`READY`、`FAILED`。
- 发布课程必须具有名称、学科和至少一个 READY 视频。
- 视频默认按文件名自然排序，家长可调整顺序；上传完成后才能进入已发布课程。
- `lastPosition` 可前后移动，`maxProgress` 只增不减；达到 90% 后标记完成。
- 仅播放状态计入有效观看时长；暂停、播放器后台停留和无效请求不计入。
- 首页继续学习取该孩子最近观看且未完成的视频。孩子之间进度、历史、收藏和统计相互隔离。
- 下架或停用不级联删除学习历史；视频删除需先阻止新播放并显式确认。

## 异常与恢复行为

- 网络中断或分片失败：显示单文件错误，可重试；可重新签发分片 URL 并继续未完成 multipart。
- 上传授权过期：API 验证原会话仍有效后重新签发，不接受过期会话继续写入。
- 容量不足：拒绝新上传并说明可用空间；不覆盖或删除已有对象以腾空间。
- 上传完成但校验失败：标记 FAILED，保留可读原因；不得出现在儿童端或满足课程发布条件。
- 对象缺失或 MinIO 不可用：API 返回可理解的播放/操作错误并记录关联 ID；页面提供重试，不泄露对象凭据。
- Cookie 失效：返回登录入口；任何 API 不得仅依赖前端路由隐藏实现权限控制。
- 数据库或服务重启：正常关停/重启后从持久化卷恢复数据；本条不表示具备故障备份能力。
- 日志记录请求关联 ID、错误类别和服务状态，不写入儿童学习数据之外的敏感认证材料。

## 验证与验收

### 自动化验证

- 领域单元测试：课程发布条件、自然排序、90% 完成、最大进度、有效时长、孩子数据隔离和配额预留。
- API 集成测试：未登录拒绝访问；家长/儿童权限边界；发布/下架；MinIO multipart 状态与清理；对象元数据校验；进度写入与查询。
- 浏览器端到端测试：家长创建课程、批量上传、发布；儿童选择档案、播放、拖动、续播；另一孩子看不到该档案的进度。

### 发布验收

- 按部署文档在全新 Ubuntu 云服务器启动，配置域名和 HTTPS；公网只能访问应用/API 与必要的 MinIO S3 API，不能访问 MinIO Console、PostgreSQL 或容器管理端口。
- 家长可在非家庭 Wi‑Fi 的手机登录；无会话无法读取课程管理 API 或播放媒体。
- 至少 20 个 MP4 可批量上传；观察到逐文件进度；测试一个文件失败重试、一次网络中断后续传和格式/容量拒绝。
- H.264/AAC MP4 可在桌面 Chrome/Edge、Android Chrome 和 iOS Safari 播放，HTTP Range 跳播生效；2 小时播放地址过期后可续签并从原位置恢复。
- 两个孩子观看同一视频时进度互不影响；切换设备后服务端进度可恢复；刷新和正常重启后资料仍存在。
- 存储接近容量上限时有告警且拒绝超额上传；错误日志不包含密码、Cookie 或可直接播放的完整签名 URL。
- 不把备份恢复、服务器容灾、跨地域复制、注册、多家庭租户、Android 安装包、转码、DRM、CDN 或公开分享列入 V1 验收。

## 部署与容量说明

- 单台 Ubuntu 云服务器运行 Caddy、Web/API、PostgreSQL、MinIO；媒体和数据库分别使用持久化目录，避免容器重建导致正常数据丢失。
- 100 GB 是产品层媒体上限，不是云服务器磁盘总容量；实际磁盘需为操作系统、数据库、multipart 暂存/未完成上传及升级预留空间。
- MinIO API 通过专用 HTTPS 主机名和精确 CORS 来源访问，桶为私有；Console 不经过公网反向代理。
- 不提供自动备份、对象版本保留或数据库恢复工具。发布说明和设置页明确提示用户自行接受数据不可恢复风险。
- 此单机方案有单点故障和单机带宽上限；V1 不承诺 SLA 或并发容量保证。

## 明确不做

原生 Android App、多家庭 SaaS/公开注册、公开分享、支付、评论、推荐流、AI/题库、复杂转码、多码率、DRM、CDN、自动备份/恢复、跨区容灾、集群部署和高可用。
